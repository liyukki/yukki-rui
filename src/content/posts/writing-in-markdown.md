## 基本语法

标题用 `##`，强调用 `**加粗**`，链接写成 `[文字](https://example.com)`。

## 代码

围栏代码块会带语法高亮：

```js
const answer = 42;
console.log(answer);
```

## 引用与列表

> 引用写成这样。

1. 有序列表第一项
2. 第二项

- 无序列表
- 第二项

## 一条建议

一篇文章只讲一件事。想讲三件事就写三篇 —— 这样标签才有意义，读者也知道该从哪篇开始。

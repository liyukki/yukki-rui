这篇文章**故意没有英文译文**，用来验证「缺译文」是正常状态：文章页的语言切换按钮应当降级跳转到英文首页，而不是报错或跳到不存在的地址。

## 基本语法

标题用 `##`，强调用 `**加粗**`，链接写成 `[文字](https://example.com)`。

## 代码

围栏代码块会带语法高亮：

```js
const answer = 42;
console.log(answer);
```

## 引用与列表

> 引用写成这样。

1. 有序列表第一项
2. 第二项

- 无序列表
- 第二项

## 一条建议

一篇文章只讲一件事。想讲三件事就写三篇 —— 这样标签才有意义，读者也知道该从哪篇开始。

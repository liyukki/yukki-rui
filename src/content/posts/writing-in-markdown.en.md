## The basics

Use `##` for headings, `**bold**` for emphasis, and write links as `[text](https://example.com)`.

## Code

Fenced code blocks get syntax highlighting:

```js
const answer = 42;
console.log(answer);
```

## Quotes and lists

> A quote looks like this.

1. The first item in an ordered list
2. The second item

- An unordered list
- A second item

## One piece of advice

Let one article do one thing. If you have three ideas, write three articles. That way the tags remain meaningful, and readers know where to begin.

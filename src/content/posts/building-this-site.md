## 为什么不用服务器

个人博客是静态内容。每篇文章在构建时就变成了 HTML 文件，没有数据库、没有登录、没有需要实时计算的东西。静态内容托管平台免费提供这件事，而且比自购服务器更快、更稳。

## 为什么不用买域名

平台会赠送二级域名。代价是地址长了点、换平台会变，但省下的是钱和每年续费的注意力。

如果你以后确实想要一个自己的域名，几十块一年的 `.top` 或 `.xyz` 就够 —— 关键是**它随时可以后加**，不构成现在动手的前提。

## 一次推送，两处上线

```yaml
# 概念示意，不是可直接使用的配置
- name: Build
  run: npm run build
```

GitHub Actions 负责构建和部署，同一个仓库也可以被 Cloudflare Pages 直接连接。任一平台出问题，另一个还在线。
